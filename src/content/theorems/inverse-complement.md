## Description

The principal arcsine and arccosine of the same input always add to a right angle. The branch intervals make the identity valid even for negative inputs.

## Conditions

−1 ≤ x ≤ 1.

## Statement

$$
\arcsin x+\arccos x = \frac\pi2.
$$

## History

Cosine developed as the sine of a complementary angle; inverse functions preserve that relationship.

## Worked example

arcsin(1/2) + arccos(1/2) = π/6 + π/3 = π/2.

## Proof sketch

If θ = arcsin x, then cos(π/2 − θ) = x and π/2 − θ lies in [0, π], the principal arccosine range.
